# Create a Website for IIT Mandi Catalyst RAMP Scheme
- Gather information on the World Bank RAMP program.
- This program also trains teachers from ITI institutes.


## Main Website
This is for the Himachal region only.
- It will list all the incubation centers under this program, which need to be displayed on the main website.
- `Currently each district (9) has total 6 centers.`
- Each institute should have its own separate page.
- It should provide details of the people involved/representing that incubation center, along with their contact information.
- List all members (protected by simple math CAPTCHA).


### Function of the Website
- The main user is an innovator with an idea in the Himachal region.
- Anyone with an idea can apply through a Google Form with their name, address, and idea.
- Once a user applies, the idea will be shared with the representative of that geographic region via email, and a record of all entries will be maintained.
- This should be CAPTCHA-protected (same as above) to prevent spam from bots.


## Government Website
This will be a dashboard for government officials to track the entire program.

**All centers will be listed, showing:**
 - How many ideas were submitted to each center
 - How many and which applicants were accepted
 - The time taken to review and respond to applications
